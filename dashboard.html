ℹ️ About the Model
Technical details of the ensemble credit scoring engine
🧠 Model Architecture — Ensemble Voting Classifier

This platform uses a soft-voting ensemble of three gradient-based models:

  • XGBoost — handles non-linear relationships, missing value tolerance
  • Gradient Boosting (sklearn) — sequential error correction, stable predictions
  • Random Forest — variance reduction, robust to outliers
🔍 Features Used
Credit Score — CIBIL/Equifax score
Debt-to-Income (DTI) — EMI burden ratio
Loan-to-Income — loan affordability
Credit Utilization — revolving credit use
Past Delinquencies — historical defaults
Employment Type — income stability proxy
